# Product

## Register

product

## Users

Sales reps and business owners doing cold outreach. They're mid-workflow: they know who they want to target (e.g. "gas stations in Austin") and need to move from intent to a clean, exportable contact list fast. They're not browsing — they're executing.

## Product Purpose

Search for local businesses by type and location using Google Places. Get a clean table of Name, Address, Phone, Website, Rating, and Maps link. Export as CSV for cold calls or CRM import. The interface should disappear into the task.

## Brand Personality

Focused, precise, fast. The tool should feel like it was built by someone who actually uses it. No decoration, no filler — every element earns its place.

## Anti-references

- Generic SaaS dashboards: card grids with gradient stat numbers, hero metrics, saturated blue/purple/teal palettes.
- Basic Bootstrap / generic admin: gray tables, blue default buttons, system fonts, looks unfinished.

## Design Principles

1. **The interface disappears into the task.** No chrome that doesn't serve the workflow. Search, results, export — that's the whole app.
2. **Speed reads as quality.** Skeleton states while loading, instant feedback on interaction. The tool should feel faster than it is.
3. **Data is the hero.** The results table is the product. Everything else frames it. Typography and spacing should make rows scannable at speed.
4. **Committed choices, no hedging.** One accent, one typeface weight range, one motion speed. Inconsistency is noise when you're reading 60 rows of business data.
5. **States are first-class.** Empty, loading, error, zero-results — each needs a specific, helpful response. Never leave the user guessing.

## Accessibility & Inclusion

WCAG 2.1 AA. Keyboard-navigable search and table. Reduced-motion safe animations. Sufficient contrast for all text including muted secondary labels.
